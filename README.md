# Exercícios do livro Introdução à Programação com Python — Nilo Menezes

Este espaço contém as minhas resoluções dos exercícios do livro “Introdução à Programação com Python”, organizadas por capítulos para acompanhar a estrutura do livro.

Objetivo: Praticar e consolidar fundamentos de Python através de exercícios progressivos.Alguns foram resolvidos, mais que uma vez, de forma diferente.

## Estrutura: 

- Cada pasta corresponde a um capítulo.
- Os exercícios estão numerados conforme o livro.
- Alguns exercícios foram resolvidos mais do que uma vez, com abordagens diferentes.
